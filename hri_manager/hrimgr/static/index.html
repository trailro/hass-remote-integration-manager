Bluetooth gives the instance the host's D-Bus, through which BlueZ offers the Bluetooth adapters. D-Bus is a powerful interface that reaches many of the host's services: turn it on only for an integration that needs Bluetooth. Home Assistant keeps using the same adapter. It can be changed later only with a new version (Update or Rebuild).

The app is called local_hri_…, starts at boot with its Watchdog on and shows in the sidebar. Lowercase letters, digits and _, starting with a letter, at most 20.

Reusing the name of a deleted instance whose /config folder was kept gives the new instance that folder (its Home Assistant, integration and credentials), but not the old options: set its password and ingress_users again on its Configuration tab before you open it to others.

Testing only: the Supervisor builds that branch or tag of hass-remote-integration on this machine (several minutes), and its code and Dockerfile run here. Use a branch you trust; not for production.
